# ZO0007 — Generated Names Shared With Another Message

**Severity:** Error

Two messages in one namespace would get the same generated names, and the generated code would not compile. This happens when:

- type arguments with the same simple name from different namespaces close one generic type, such as `Envelope<Sales.Order>` and `Envelope<Billing.Order>`: both would get `EnvelopeOfOrderOutboxWriter`; or
- a generic and a non-generic message, or two generic messages of different arity, have the same name in one namespace, such as `Foo` and `Foo<T>`: both would get `AddFooOutbox()`.

No code is generated for the generic message or the closed constructions involved. A non-generic message keeps its code.

---

## Example

```csharp
[assembly: OutboxMessage(typeof(Envelope<Sales.Order>))]
[assembly: OutboxMessage(typeof(Envelope<Billing.Order>))]   // ZO0007 for both
```

---

## How to fix

Rename one of the types involved, or move the generic message to a namespace of its own.
