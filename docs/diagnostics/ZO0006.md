# ZO0006 — Invalid OutboxMessage Declaration of a Closed Generic Type

**Severity:** Error

An `[OutboxMessage]` declaration cannot be generated as written. The message says which case applies:

- `[assembly: OutboxMessage]` names no type.
- `[assembly: OutboxMessage(typeof(Envelope<>))]` names an open generic type instead of a closed construction.
- `[assembly: OutboxMessage(typeof(Order))]` names a non-generic type. The assembly form is for closed generic types; mark `Order` itself with `[OutboxMessage]`.
- The generic type is not marked `[OutboxMessage]`, or is declared in another assembly.
- `[OutboxMessage(typeof(...))]` is applied to a type declaration. That form is valid only on the assembly.
- A type in the closed construction is private, protected or file-local, so the generated writer and dispatcher, which live elsewhere in the assembly, cannot name it. This is reported where an `IOutboxWriter` or `IOutboxDispatcher` of it is used.

---

## Example

```csharp
// ZO0006: Envelope<> is open
[assembly: OutboxMessage(typeof(Envelope<>))]
```

---

## How to fix

Name a closed construction of a generic type that is marked `[OutboxMessage]` in the same assembly, and make every type in it at least `internal`:

```csharp
[assembly: OutboxMessage(typeof(Envelope<Order>))]
```
