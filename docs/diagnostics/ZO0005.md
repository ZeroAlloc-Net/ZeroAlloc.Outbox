# ZO0005 — Stored Type Name Too Long

**Severity:** Error

The stored type name of a closed generic message, such as `MyApp.Envelope<MyApp.Order>`, is longer than 256 characters. Every outbox store keeps the name in a `TypeName` column of at most 256 characters, so the message could not be stored. No code is generated for that closed construction.

---

## Example

```csharp
// ZO0005 when the fully qualified names add up to more than 256 characters
public sealed class Handler(IOutboxWriter<Envelope<Some.Very.Long.Namespace.WithAVeryLongTypeName>> writer);
```

---

## How to fix

Shorten the namespace or the names of the generic type or its type arguments. See [Stored type name of a closed construction](../message-types.md#stored-type-name-of-a-closed-construction) for how the name is built.
